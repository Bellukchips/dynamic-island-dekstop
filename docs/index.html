Notch untuk desktop-mu

Pil kecil di tepi layar yang membuka hub berisi media, lirik, cuaca, timer, pengingat, catatan, clipboard, dan shelf file. Dengan mata yang mengikuti kursormu.

Unduh rilis Lihat di GitHub
Windows · Linux (X11 / Wayland) · dibuat dengan Tauri 2 + Rust + TypeScript

Semua fitur

Halaman hub bisa diaktifkan, dimatikan, dan diurutkan lewat Pengaturan.

🎵

Media

Judul, artis, cover album, kontrol putar/jeda/lanjut, dan geser progress untuk pindah menit. Warna aksen mengikuti cover.

🎤

Lirik

Lirik bersinkron dengan lagu, dengan baris aktif langsung di tampilan ringkas notch.

🕒

Jam & kalender

Jam dan tanggal di notch. Klik tanggal untuk kalender bulanan dengan hari libur dan peringatan Indonesia.

🌦️

Cuaca

Suhu, terasa seperti, kelembapan, dan peringatan hujan beberapa menit sebelumnya.

🔋

Baterai

Persentase, status mengisi, dan peringatan baterai rendah lewat ekspresi mata.

🍅

Timer Pomodoro

Fokus, istirahat, dan istirahat panjang. Durasi dan jumlah ronde bisa diatur.

⚡

Kontrol cepat

Mic, Wi-Fi, Bluetooth, keep awake, dan tema gelap/terang dalam satu halaman.

📈

Status sistem

CPU, RAM, serta kecepatan unduh dan unggah secara langsung.

⏰

Pengingat

Pilih tanggal dan jam, ulang harian atau bulanan, bunyi pengingat, lalu tunda 5 menit atau selesai.

📝

Catatan

Simpan catatan cepat dan buka detailnya di jendela tersendiri. Tersimpan permanen.

📋

Riwayat clipboard

Klik item untuk menyalin ulang, atau bersihkan semuanya.

🗂️

Shelf file

Seret file ke notch untuk menyimpannya sementara, lalu seret keluar ke File Explorer atau aplikasi lain.

🕌

Jadwal shalat

Jadwal harian dan pengingat waktu shalat lewat kartu kecil.

🔒

Indikator privasi

Titik penanda dan kartu saat mikrofon atau kamera sedang dipakai aplikasi.

🔌

Kartu perangkat

Pemberitahuan saat Bluetooth, USB, charger, keyboard, atau mouse dicolok dan dicabut.

🔊

HUD volume & kecerahan

Indikator volume dan kecerahan tampil di notch, termasuk status mute.

👀

Mata ekspresif

Mata mengikuti kursor, berkedip, dan berganti ekspresi. Ada 10 tema mata dari aurora sampai monochrome.

🧲

Geser sesuka hati

Tahan lalu geser notch (berubah jadi bola), menempel ke tepi atas, bawah, kiri, atau kanan. Reset posisi dari tray.

🎨

Tema & skala

Otomatis, terang, gelap, atau warna kustom. Ukuran 0,5× sampai 1,5×. Berubah langsung dari Pengaturan.

🔔

Banner update

Memberi tahu saat ada versi baru dan membuka halaman rilisnya.

Pasang & jalankan

Butuh Rust (stable), Node.js 18+, dan pustaka sistem Tauri. Rinciannya per sistem operasi ada di README.

git clone https://github.com/USERNAME/REPO.git
cd REPO
npm install
npm run tauri dev      # mode pengembangan
npm run tauri build    # buat installer

Kontrol

Hover untuk membuka hub, klik untuk pindah, scroll atau ikon di atas untuk ganti halaman.

AksiHasil
Hover / klik notchBuka hub
Scroll mouse atau touchpadGanti halaman
Tahan lalu geserPindahkan notch
Klik kanan item shelfTampilkan di folder
Seret file ke notchSimpan ke shelf
Ikon trayPengaturan, Pusatkan Notch, Keluar

Konfigurasi

Semua bisa diatur dari jendela Pengaturan atau langsung di config.toml.

scale = 1.0
pages = ["media", "clock", "weather", "battery", "timer", "quick",
         "stats", "reminder", "notes", "clipboard", "shelf", "lyrics",
         "privacy", "prayer"]

[appearance]
theme = "auto"        # auto | light | dark | custom
default_mood = "normal"
eye_theme = "aurora"
