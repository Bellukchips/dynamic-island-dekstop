01 / Indeks fitur

Semua mudah dijangkau.

Halaman hub bisa diaktifkan, dinonaktifkan, dan diurutkan melalui Pengaturan. Sisakan alat yang benar-benar kamu gunakan.

Media

Judul, artis, cover album, kontrol pemutaran, dan progress bar. Warna aksen dapat mengikuti cover album.

Lirik tersinkron

Lirik mengikuti lagu yang diputar. Baris aktif juga tampil di notch ringkas.

Jam & kalender

Jam dan tanggal sekilas. Buka kalender bulanan beserta hari libur Indonesia dari tampilan tanggal.

Cuaca

Suhu, suhu terasa, kelembapan, dan peringatan ketika hujan diperkirakan segera turun.

Baterai & perangkat

Persentase dan status pengisian baterai, serta kartu saat USB, Bluetooth, charger, keyboard, atau mouse tersambung maupun dilepas.

Timer fokus

Pomodoro untuk fokus, istirahat singkat, dan istirahat panjang. Atur durasi sesi dan jumlah ronde.

Kontrol cepat

Akses cepat ke mikrofon, Wi-Fi, Bluetooth, keep-awake, serta tampilan terang/gelap jika didukung.

Status sistem

Penggunaan CPU, RAM, swap, dan penyimpanan secara langsung, kecepatan unduh dan unggah jaringan, jumlah proses, uptime, serta info sistem operasi.

Pengingat

Tentukan tanggal dan jam, ulangi harian atau bulanan, aktifkan bunyi, tunda, atau tandai pengingat selesai.

Catatan permanen

Simpan catatan cepat dan buka detailnya di jendela terpisah. Catatan tetap tersimpan.

Riwayat clipboard

Lihat isi clipboard terbaru, salin ulang item, atau bersihkan riwayat.

Shelf file

Seret file ke notch agar mudah diakses sementara, lalu seret kembali ke File Explorer atau aplikasi lain.

Jadwal shalat

Jadwal shalat harian, mode pengingat (adzan, nada, atau senyap), pengingat sebelum waktu masuk, dan audio adzan. Selama adzan berbunyi, notch menampilkan kartu atau awan percakapan yang tidak tertutup oleh klik, dan media yang sedang berjalan dijeda lalu dilanjutkan setelah adzan selesai.

Mode Ramadan

Aktifkan dari tombol Ramadan di halaman shalat. Notch melebar dan menampilkan hitung mundur menuju imsak (sahur) dan Maghrib (buka puasa), imsakiyah hari ini lengkap dengan imsak, subuh, terbit, dzuhur, ashar, maghrib, dan isya, serta kartu dzikir setelah adzan yang bisa digeser. Setelah adzan selesai, notch menampilkan pengingat dzikir. Memakai jadwal shalat yang sudah tersimpan, dan pilihan aktif atau tidaknya diingat.

Indikator privasi

Menampilkan indikator dan kartu pemberitahuan saat mikrofon atau kamera sedang digunakan.

Mode rapat

Aktif otomatis saat kamera atau mikrofon dipakai (butuh indikator privasi menyala). Notch menampilkan timer durasi rapat beserta status kamera dan mikrofon, dalam bentuk awan percakapan atau kartu. Selama rapat, sapaan dan komentar Conversation Moments ditahan dan dibuang, bukan diputar belakangan, sehingga tidak ada notifikasi yang mengganggu. Begitu rapat selesai, notch menampilkan ringkasan lama rapat.

Mata uang & ringkasan pasar

Konversi Rupiah ke mata uang pilihan dan lihat performa bulanan saham pilihan di Bursa Efek Indonesia. Membutuhkan akses jaringan dan sumber data pasar yang dapat diakses.

Alert kurs & harga

Dapatkan pemberitahuan di notch saat kurs mata uang atau harga saham yang kamu pantau mencapai angka yang kamu tentukan, tanpa perlu membuka halaman Currency.

HUD volume & kecerahan

Indikator volume dan kecerahan tampil di dalam notch, termasuk status mute jika tersedia.

Mata ekspresif

Mata mengikuti kursor, berkedip, dan berganti di antara delapan ekspresi serta sepuluh tema.

Istirahat mata 20-20-20

Setiap 20 menit, mata notch mengajakmu menatap objek yang jauh selama 20 detik. Cocok untuk notch yang punya mata dan skin mata sendiri, jadi pengingatnya terasa seperti ajakan dari teman, bukan alarm.

Greeting suara

Notch menyapamu dengan suara setiap kali dijalankan, termasuk setelah komputer menyala. Pilih sapaan otomatis sesuai jam, acak, atau tulis kalimatmu sendiri. Bisa dicoba dulu dari Pengaturan.

Conversation Moments

Komentar singkat berupa teks, tanpa suara, di momen yang pas: musik mulai atau berganti lagu, cuaca berubah atau hujan segera turun, baterai menipis, atau saat kamu kembali setelah lama pergi. Atur momen yang aktif dan jedanya, dan pesan tidak pernah menimpa kartu penting seperti adzan atau pengingat, serta dibungkam otomatis selama Mode rapat.

Focus Companion

Teman untuk sesi Pomodoro. Notch memberi semangat saat sesi fokus dimulai, saat setengah jalan, ketika sesi selesai, dan saat waktu istirahat berakhir.

Pesan saat pointer diam

Kalau pointer tidak bergerak cukup lama, notch menyapa dengan pesan imut seperti “Kamu kemana, kok diam saja?”. Atur lama diam, teks, emoji, dan ekspresi mata. Bisa disembunyikan saat musik atau video sedang diputar.

Seret, tempel, dan pindahkan

Seret notch ke mana pun. Notch dapat berubah menjadi bola mengambang dan menempel di tepi atas, bawah, kiri, atau kanan.

Tampilan

Warna otomatis, terang, gelap, atau kustom, dengan skala tampilan dari 0,5× sampai 1,5×.

Pembaruan & gerakan

Pemberitahuan rilis baru dan gerakan acak yang halus sebagai opsi.

02 / Setup pengembang

Build di komputer sendiri.

Situs dokumentasi terpisah dari aplikasi Tauri. Vite hanya membundel halaman HTML yang didaftarkan di konfigurasi proyek. Publikasikan folder docs/ melalui Settings → Pages pada repositori GitHub.

Pasang toolchain Rust stable, Node.js versi 18 atau lebih baru, Git, dan pustaka native yang dibutuhkan Tauri pada sistem operasi yang digunakan.

Windows: pasang Microsoft C++ Build Tools dengan workload Desktop development with C++, dan pastikan WebView2 Runtime tersedia.

Ubuntu / Debian: pasang WebKitGTK 4.1, build tools, OpenSSL, AppIndicator, librsvg, dan paket pengembangan GTK layer-shell.

Arch Linux: pasang WebKitGTK 4.1, base-devel, OpenSSL, AppIndicator, librsvg, xdotool, dan GTK layer-shell.

  • Prasyarat platform Tauri
  • Instalasi Rust
  • Unduh Node.js
01

Clone repositori

Gunakan URL repositori proyek ini.

git clone https://github.com/bellukchips/dynamic-island-dekstop.git
cd dynamic-island-dekstop
02

Pasang dependensi

Pasang paket frontend. Cargo akan mengunduh dependensi Rust saat build.

npm install
npm install --save-dev @types/node
03

Jalankan atau build

npm run tauri dev
npm run tauri build

04 / Konfigurasi

Atur hub sesuai kebutuhan.

Gunakan jendela Pengaturan atau ubah config.toml langsung. Urutan halaman mengikuti ID di dalam daftar pages.

Rust membaca config.toml dan menyediakan pengaturannya ke frontend sebagai window.__CFG__. Nilai kosong menggunakan default di main.ts.

Hapus ID halaman untuk menyembunyikannya atau tambahkan agar tampil di hub. Perubahan Pengaturan diteruskan melalui event config-changed.

Posisi notch yang diseret disimpan di bagian [position] melalui custom, x, dan y.

Mode Ramadan memakai halaman prayer, jadi pastikan ID itu ada di daftar pages. Mode rapat bergantung pada indikator privasi (privacy) agar kamera dan mikrofon terdeteksi.

scale = 1.0
pages = [
  "media", "clock", "weather", "battery", "timer",
  "quick", "tools", "stats", "reminder", "notes",
  "clipboard", "shelf", "lyrics", "privacy", "prayer",
  "currency"
]

[appearance]
theme = "auto"          # auto | light | dark | custom
default_mood = "normal"
eye_theme = "aurora"
